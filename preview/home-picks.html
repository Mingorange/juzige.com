真实 Agent 案例 · 提示词拿走就能用

内容创作 · 短剧 AGENT · 60 集 / 8 天

字节短剧 Agent 的内测案例：4 万多字剧本交进去，Agent 负责角色设定、按剧本拆分镜、渲染场景，产出一份能逐镜头编辑的「故事蓝图」，团队只在关键点微调。上线 4 天抖音播放破 1 亿，单集成本约 ¥500–1,000。缺陷也真实：等待久、偶有裁切和字幕乱码，排期要留人工审片时间。

做产品 · CLAUDE CODE · 订阅约 $1,000/月

一个主编排 Agent 先审规格书、用 git 盯进度，再把独立模块分给一群子 Agent 并行干活：独立的活并行跑，便宜的活交给便宜的模型。网店、SaaS、Steam 游戏同时推进，订阅合计约 $1,000/月。教训先行：开工前给每个模块定好验收标准和预算上限，再开闸。

抄作业提示词 · 英文原版
Here is my spec for [product, e.g. small web shop or indie game]: [paste spec or file path]. Break it into independent modules, write a short brief for each with inputs, outputs and acceptance tests, then work through them using sub-agents in parallel where they don't depend on each other. When all modules pass their tests and are integrated, give me a summary of what was built and what is left, and ask before deleting any files or deploying anything.

省钱 · CLAUDE · 43 家实测

把同一家酒店在多个平台的报价拉齐，算进旅游税和到店杂费，才是真总价——同房几小时内能差约 60%。可落地的打法：先订可退改价（最多贵约 11%，有时不到 2%），再让 Agent 每天复查，到取消截止日前降价就取消重订。

抄作业提示词 · 英文原版
Find [hotel name] in [city] for [check-in] to [check-out], [number] guests, on [sites, e.g. Booking.com, Expedia, the hotel's own site]. For each, record the room type, nightly rate, taxes, resort and other fees, and cancellation policy, then calculate the true total. Give me a comparison table ranked by total cost, and do not book anything.

搞钱 · CHATGPT AGENT · 几周 → 几小时

把客户名单交给 ChatGPT 的 Agent 模式：逐家查官网和 LinkedIn，把行业、规模、总部、关键联系人、近期动态补进 CRM，缺的字段标出来。诚实提醒：这则目前只有演示口述、没展示真实跑通结果——先拿 3 家小名单试跑、核对无误再放大。

Then fill in the matching fields in my CRM at [CRM link] and mark any value you could not verify. Do the first 3 and show me before continuing, and don't send emails or overwrite existing data without asking.
