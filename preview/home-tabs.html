真实 Agent 案例 · 提示词拿走就能用

做产品 · Replit Agent · 首单 / 8–9 个月

一位非程序员用 Replit Agent 做了个市场调研 SaaS，基本只在周末干活：第一版 2–3 个月上线，随后 5–6 个月按 Reddit 用户反馈打磨到真正好用，还上了 Product Hunt。零付费推广，流量和反馈都来自 Reddit 自然帖；第一单在发帖前一个月到手。

抄作业提示词 · 中文版
帮我为[目标客户]做一个[产品类型，例如市场调研工具]网页应用。先提出核心功能和一个能拿给人看的简单第一版，然后一步步搭建，包含注册、[核心功能]和收款方式。在连接任何收款账户或正式发布之前，先停下来问我。
原文案例 → 
Help me build a [type of product, e.g. market research tool] web app for [target customer]. Start by proposing the core features and a simple first version I can show people, then build it step by step with sign-up, [key feature] and a way to take payment. Pause and ask me before you connect any payment account or publish it live.

知识管理 · OpenClaw · 每日议程 + 晚间复盘

作者用 OpenClaw 跑了一个 Agent，直接连他的 Obsidian 笔记库：任务、日历和每日笔记都在库里，笔记库就是唯一事实来源。每天早上发当日议程，白天跟进进度，晚上发带效率分和反思问题的复盘；手机上用 Discord 对话，随时建任务、改期、打卡习惯。

抄作业提示词 · 中文版
连接我的 Obsidian 笔记库（位于[笔记库路径]）和我的[Discord/聊天应用]。每天早上[时间]，根据我的任务和笔记发一份议程，晚上跟进进度。当我发消息时，在笔记库里创建或重新安排任务、标记习惯已完成；在删除或覆盖任何笔记之前先问我。
原文案例 → 
Connect to my Obsidian vault at [vault path] and my [Discord/chat app]. Every morning at [time], send me an agenda built from my tasks and notes, and check in on progress in the evening. When I message you, create or reschedule tasks and mark habits done in the vault; ask me before you delete or overwrite any note.

效率 · Claude Cowork · 62 封 / 7 天 · 59 封原样通过

作者让 Agent 在职业邮箱上跑了一周：先喂约 180 封历史邮件和一份业务背景文档学语气，把活拆成先分类再处理，并立规矩——投诉、纠纷、合同问题一律转人工。第 7 天 Agent 处理了 62 封邮件，59 封原样通过，复核只要 12 分钟。

抄作业提示词 · 中文版
处理我[邮箱账号]过去[天数]天内需要回复的邮件。对每一封，用我过去已发邮件作参考，按我的语气写一封草稿回复，只保存为草稿，不要发送。完成后给我一份草稿清单，并标出哪些地方你不得不猜测事实、日期或承诺。
原文案例 → 
Go through my inbox for [email account] over the last [number] days and read every message that needs a reply. For each one, write a draft reply in my voice, using my past sent emails as a guide, and save it as a draft only. Do not send anything; when you are finished, give me a list of the drafts and flag any where you had to guess at facts, dates or commitments.

做产品 · n8n · $500 / 一单

为一家书店老板做的 n8n 接单系统：消息先进 AI 分类器，语音转文字、图片识商品，Supabase 搜索查书；确认购买后由下单 Agent 锁进下单状态，收齐收货信息、走货到付款或银行转账。客户得到 24/7 即时回复，老板省下大量重复问答和查库存的时间。运行成本约 Supabase $25/月加 VPS $100/年。

抄作业提示词 · 中文版
帮我为[商家名称]搭建一个 n8n 工作流，接收 WhatsApp 消息。它要能转录语音、描述图片，并判断顾客是否想买[商品]。如果是，把订单详情交给第二个 Agent，在[订单系统]里准备订单。在下单或给顾客发回复之前，先停下来等我批准。测试语音和测试照片各出一份正确的订单摘要，就算完成。
原文案例 → 
Help me build an n8n workflow for [business name] that receives incoming WhatsApp messages. It should transcribe voice notes, describe any images, and work out whether the customer wants to buy [products]. If so, it should pass the order details to a second agent that prepares the order in [order system]. Pause for my approval before placing any order or sending any reply to a customer. You're done when a test voice note and a test photo each produce the correct order summary.

生活效率 · ChatGPT Agent · $25 虚拟卡 / 走到结账

作者给 Agent 一张 $25 的虚拟借记卡买礼物：Agent 自己逛商店、比商品、一路走到结账，全程没人帮忙；但最后一公里没过去——验证码、动态定价和拦截自动化浏览器的商店把它挡住了。教训是：身份验证、反机器人检查和付款确认要留给人处理。

抄作业提示词 · 中文版
为[收礼人及其兴趣]找一份礼物，总价不超过 $[25]（含运费和税）。逛几家店，至少比较 [3] 个选项的价格、评价和送达时间，并推荐一个、说明理由。带到结账页面后停下，不要输入付款信息或下单，把商品、最终价格和收货地址给我确认。如果某家店拦截你或弹出验证码，跳过它并告诉我是哪一家。
原文案例 → 
Find a gift for [recipient, with their interests] under $[25] total including shipping and tax. Browse a few stores, compare at least [3] options on price, reviews and delivery time, and recommend one with reasons. Take it to the checkout page but stop before entering payment details or placing the order, and show me the item, final price and shipping address for approval. If a store blocks you or shows a CAPTCHA, skip it and tell me which one.
